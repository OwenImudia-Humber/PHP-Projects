# PHP Projects

## Overview

This repository contains PHP programming labs, exercises, and projects completed as part of my Computer Programming & Analysis studies at Humber College.

The purpose of this repository is to document my progress in PHP development, demonstrate my understanding of server-side programming, and showcase practical programming concepts through coursework and hands-on exercises.

## Technologies & Concepts

- **PHP:** Server-side programming and application development.
- **HTML:** Structuring web pages and forms.
- **CSS:** Basic web styling and presentation.
- **Object-Oriented Programming (OOP):** Classes, objects, properties, and methods.
- **PHP Functions:** Creating reusable functions and organizing code.
- **PHP Arrays:** Working with indexed and associative arrays.
- **Form Handling:** Processing user input and handling form submissions.
